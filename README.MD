# Gestor de Tareas

Aplicación web que permite registrar, organizar y administrar tareas de manera sencilla e interactiva, sin necesidad de recargar la página.

## Descripción del proyecto

El proyecto **Gestor de Tareas** consiste en una aplicación web desarrollada con HTML, CSS y JavaScript. Su propósito es facilitar la administración de actividades mediante una interfaz que permite agregar tareas, marcarlas como completadas, eliminarlas y visualizar la cantidad de tareas pendientes.

El desarrollo se realizó de manera colaborativa utilizando Git y GitHub para gestionar los cambios e integrar el trabajo de los tres integrantes.

## Funcionalidades

- **Agregar tareas:** permite registrar nuevas actividades mediante un formulario.
- **Completar tareas:** permite marcar las actividades que ya fueron realizadas.
- **Eliminar tareas:** permite quitar actividades de la lista.
- **Contador de pendientes:** muestra la cantidad de tareas que todavía no se han completado.
- **Actualización dinámica:** modifica la interfaz mediante JavaScript sin recargar la página.
- **Validación de campos:** evita registrar tareas con texto vacío.

## Control de versiones

Para organizar el trabajo colaborativo se utilizaron las siguientes ramas:

- `main`: rama principal y estable del proyecto.
- `feature/estilos`: desarrollo de la interfaz visual mediante CSS.
- `feature/javascript`: implementación de las funcionalidades mediante JavaScript.

Los cambios se integraron mediante Pull Requests, permitiendo revisar las modificaciones antes de incorporarlas a la rama principal.

## Ejecución del proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta `Gestor_de_Tareas`.
3. Ejecutar el archivo `index.htm` en un navegador web.
4. Utilizar el formulario para registrar y administrar las tareas.
